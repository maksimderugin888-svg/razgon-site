# RAZGON — продающий сайт студии цифровых технологий

Одностраничный лендинг: Telegram-боты, сайты и веб-приложения, ИИ-контент
(песни, видео, аватары), игры и Mini Apps. Чистые HTML/CSS/JS — ноль библиотек,
ноль сборки. Открыл `index.html` — работает.

## Структура

```
index.html      — вся страница (тексты правятся прямо здесь)
css/style.css   — стили (палитра — в :root наверху файла)
js/main.js      — интерактив (Telegram-юзернейм — первая константа файла)
js/hero-fx.js   — живой фон hero (частицы + нейросеть)
js/quiz.js      — квиз «Подбор за 4 вопроса» (вопросы и матрица решений — внутри)
js/chat.js      — чат-помощник на сайте (база знаний KB — внутри)
bot/            — Telegram-бот заявок @razgonstudio_bot (см. bot/README)
```

## Конверсионные инструменты

- **Квиз-подбор** (секция [05]): 4 вопроса → готовое решение с ценой и сроком
  → заявка копируется в буфер → чат бота. Матрица решений — в `js/quiz.js`.
- **Чат-помощник** (кнопка ⚡ справа внизу): мгновенные ответы на типовые
  вопросы из локальной базы знаний, нестандартное уводит в Telegram.
  Позиционируется честно: «мини-демо ИИ-сотрудника». Ответы — в `js/chat.js` (KB).
- **Калькулятор сметы** (в прайсе): 7 позиций, включая подписку ИИ-сотрудника
  (`data-monthly`) — сумма показывает «от X ₽ + Y ₽/мес».

## Что заменить перед запуском

1. **Telegram** — в `js/main.js` первая строка кода:
   `const TG_USERNAME = 'razgon_studio'` → ваш юзернейм (аккаунт или бот).
   Все кнопки сайта подхватят его автоматически. Продублируйте юзернейм
   в футере `index.html` (строка «telegram: @…»).
2. **Почта** — `hello@razgon.studio` в футере `index.html`.
3. **Кейсы и отзывы** — сейчас это правдоподобные ЗАГЛУШКИ для демонстрации
   структуры. Замените на реальные проекты и цитаты (или удалите секции),
   прежде чем показывать сайт клиентам: обещание «кейсы без фотошопа»
   обязывает.
4. **Цены** — вилки в секции прайса и в калькуляторе
   (`data-price` / `data-name` у чекбоксов в `index.html`).
5. **Пульс студии** — строка «в работе: 4 проекта» в hero: поставьте своё
   число (дата слота считается автоматически: сегодня + 6 дней).

## Фишки

- Скрэмбл-расшифровка заголовка, курсор-прицел (только desktop),
  бегущие тикеры, меняющие направление со скроллом
- Sticky-процесс с подсветкой шагов, 3D-наклон карточек кейсов
- Калькулятор сметы: собирает выбор в готовое сообщение
  и открывает Telegram с текстом заявки (`t.me/…?text=`)
- Пасхалка: 5 быстрых кликов по логотипу — «РЕЖИМ ТУРБО»
  (выход — один клик по логотипу)
- `prefers-reduced-motion` уважается: все анимации гаснут до статики

## Бонус: fx/ — кинематографичная петля + готовые видео

`fx/ai-loop.html` — самодостаточная страница: бесшовная luxury-анимация «ИИ-мир»
(голографические панели кода, нейросеть с бегущими API-сигналами, частицы,
кибер-сетка, объёмные лучи, медленный наезд камеры).

- **Готовые видео** (1920×1080, 60 fps, ровно 20.000 с, идеальный луп):
  `fx/ai-loop-blue.mp4` (синяя, OpenAI/Stripe-вайб) и
  `fx/ai-loop-razgon.mp4` (фирменная: чёрный + кислотный + оранж).
- Петля бесшовная математически (проверено попиксельно: кадры t=0 и t=LOOP
  совпадают до бита).
- Параметры страницы: `?theme=razgon` — фирменная палитра;
  `?size=4k | fhd | 1600x900` — внутреннее разрешение рендера.
- Кнопка «⏺ rec loop» (правый верх) пишет один круг в `.webm`
  → в mp4: `ffmpeg -i loop.webm -c:v libx264 -crf 16 -pix_fmt yuv420p out.mp4`.
- Применение: фон промо-роликов, заставка, фон секции сайта.

**Фон hero на самом сайте** — `js/hero-fx.js` (+ `<canvas class="hero-fx">`
в `index.html`): лёгкая версия в фирменной палитре — частицы и нейросеть
с пробегающими кислотными сигналами. Рисует только пока hero на экране,
гаснет при prefers-reduced-motion. Интенсивность — `opacity` у `.hero-fx`
в `css/style.css` (сейчас 0.55).

## Запуск локально

Просто открыть `index.html` в браузере, либо:

```bash
python3 -m http.server 8080
# → http://localhost:8080
```

## Деплой

Статика без бэкенда — годится любой хостинг: GitHub Pages, Cloudflare Pages,
Netlify, Vercel или своя VPS (nginx на папку). Один каталог — один сайт.
